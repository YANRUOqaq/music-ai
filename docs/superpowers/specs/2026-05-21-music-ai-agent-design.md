# Music AI Agent — 设计规格书

## 概述

一个跨平台桌面应用（Windows + macOS），作为工作时的音乐 AI 伙伴。用户可以导入歌单让 AI 学习音乐偏好，AI 自动播放符合口味的音乐，同时提供闲聊陪伴。拥有可自定义的性格设定。

## 技术架构

| 层级 | 技术选型 |
|------|---------|
| 桌面壳 | Electron |
| 前端 UI | React + TypeScript |
| 后端 | Node.js（Electron 主进程） |
| 音乐引擎 | NeteaseCloudMusicApi（子进程，本地 HTTP） |
| AI 对话 | 云端 LLM API（支持 Claude / GPT） |
| 数据存储 | 本地 SQLite + JSON 配置文件 |
| 跨平台 | Windows + macOS 同一套代码 |

## 四大数据流

1. **导入歌单** → LLM 分析歌单特征 → 输出偏好画像（自然语言）→ 存入本地
2. **智能播放** → 偏好画像 → LLM 生成推荐关键词 → 网易云 API 搜索 → 播放队列
3. **闲聊对话** → 用户消息 + 偏好画像 + 当前播放状态 → LLM → 回复
4. **偏好进化** → 用户跳过/点赞反馈 → 修正偏好画像

## 偏好学习机制

用户导入歌单（来自 QQ 音乐、网易云等任意来源）后：

1. 提取歌单中每首歌的元信息（歌名、歌手、专辑、风格标签）
2. 将元信息打包发送给 LLM，要求输出偏好画像
3. 偏好画像为自然语言描述，例如：
   > "用户偏好华语流行为主（~60%），特别喜欢周杰伦、林俊杰这类旋律型歌手。
   > 次要偏好后摇和氛围电子（~25%），用于专注工作时听。反感说唱和重型摇滚。
   > 情绪倾向：工作时喜欢舒缓不打扰的背景音乐，休息时喜欢有律动的流行歌。"
4. 画像存入本地，可随时查看和手动编辑
5. 播放中收集反馈（跳过=负反馈，听完+点赞=正反馈），定期用 LLM 更新画像

## 聊天 AI 配置

- 支持 Claude API 和 OpenAI API，用户可在设置中切换
- 每轮对话注入：系统 Prompt（性格设定 + 偏好画像）+ 当前播放歌曲信息
- 性格设定示例："你是一个叫小音的AI朋友，性格温暖但偶尔毒舌，喜欢用音乐比喻生活..."
- 上下文窗口保留最近 20 轮对话 + 偏好画像

## 错误处理

- 网易云 API 不可用 → 提示用户检查网络，自动重试 3 次
- LLM API 调用失败 → 降级为本地规则推荐（基于标签匹配）
- 歌单解析失败 → 显示具体哪首歌/哪条数据有问题，跳过继续
- 歌词/封面获取失败 → 静默降级，不影响播放

## 成功标准

1. 用户导入歌单后，5 分钟内生成可用的偏好画像
2. AI 推荐的歌曲与用户已有歌单的风格匹配度 > 70%（用户主观评分）
3. 聊天延迟 < 3 秒（取决于 LLM API 响应速度）
4. 应用内存占用 < 300MB（含 Electron + 网易云 API 子进程）
5. 跨平台构建：同一代码库在 Windows 和 macOS 均能打包运行
